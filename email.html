5. Self-host kit Needs an AI API key

Run your AI on your own server with your own address (for example chat.yourbusiness.com). The kit is one file that serves a chat page, a chat bubble and the connection to the AI.

  1. Get an AI API key. We recommend an AIV API key.
  2. Open your AI, go to Deploy, and press Download self-host kit. Unzip it.
  3. Create a free account at cloudflare.com, then go to Workers & Pages, Create, Create Worker, give it a name and press Deploy.
  4. Press Edit code, delete everything, paste the contents of worker.js from the kit, and press Deploy.
  5. Go to Settings, Variables and Secrets, + Add. Choose Secret, name it AI_API_KEY, paste your API key and press Deploy.
  6. Open your worker's address (shown on its page). That's your AI's chat page.
  7. For a bubble on your site, paste <script src="https://YOUR-WORKER-ADDRESS/widget.js" defer></script> before </body>.
  8. Optional: under Settings, Domains & Routes, add your own domain.

Using a different AI company? Add Text variables AI_BASE_URL (for example https://api.openai.com/v1) and AI_MODEL (for example gpt-4o-mini). The kit includes your AI's instructions, so it works with any OpenAI-compatible API. The README in the kit explains every setting.

6. Use it in your own app (API) Needs an AI API key

Developers can use Dinner Buddy in apps, websites and tools through the AIV API. It works with any OpenAI-compatible library.

  1. Get an AIV API key.
  2. Use base URL http://127.0.0.1:8787/v1 and model bot-Awvmj5y97u8z.
  3. Keep your key on your server, never in a web page or app that people download.
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.AIV_API_KEY,   // your AIV key; keep it on your server
  baseURL: "http://127.0.0.1:8787/v1",
});

const reply = await client.chat.completions.create({
  model: "bot-Awvmj5y97u8z",
  messages: [{ role: "user", content: "Hi!" }],
});
console.log(reply.choices[0].message.content);

Change your AI's settings

You can update Dinner Buddy anytime, as often as you like (up to 15 updates a day).

  1. Open your AI with your private manage link (open it now). It opens the AI Verse builder with your AI loaded.
  2. Change anything in the form:
    What it knows: the description, schedule or hours, location, facts about you, how you want help, your website, uploaded files and notes.
    Personality: its name, first message, tone (friendly, professional, playful or concise) and color.
  3. Press Update my AI (or Update chatbot). The builder re-reads your website and files, and you can test the changes in the chat preview right away.
