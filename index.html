Setup guide

Get your free Groq key

Step 1

Create a Groq account

Go to console.groq.com and sign in with Google, GitHub or email. No credit card is needed for the free tier.

Step 2

Create an API key

Open API Keys and choose Create API Key. Copy it right away, since Groq shows it only once. It starts with gsk_.

Step 3

Paste it into the app

In any AI Verse app, open Settings → AI provider → Groq key, paste the key, then press Test connection.

Your key is saved only in your browser and sent only to Groq. You can delete it or create a new one at any time.
