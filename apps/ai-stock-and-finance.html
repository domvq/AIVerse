Setup

Ollama

  1. Install from ollama.com and download a model, e.g. ollama pull qwen3:8b (7–8B models or larger work best for planning and email).
  2. Allow this site to talk to Ollama by setting OLLAMA_ORIGINS to , then restart Ollama.
    Mac: launchctl setenv OLLAMA_ORIGINS "" · Windows: add it under System → Environment Variables · Linux: OLLAMA_ORIGINS= ollama serve

LM Studio

  1. Load a model, open the Developer tab and start the server.
  2. Turn on Enable CORS in the server settings.

If your browser asks to let this site access devices on your local network, allow it.

A small model downloads once into this browser and runs on your graphics card — fully private, and it works offline afterwards. Needs Chrome or Edge with WebGPU. Answers are simpler than cloud models. Reading statement photos needs a vision model from another provider; CSV and PDF statements work with any model.
