What it is

One address, every AI Verse tool

MCP (Model Context Protocol) is an open standard that lets AI apps use tools from other services. Add the AI Verse server once, then just ask.

Works where you already chat

Claude, ChatGPT, Cursor, VS Code and other MCP apps can call AI Verse tools when your request needs them.

Free to start

No account needed. Try every tool with a daily allowance of free AI tool calls.

Real results with links

Songs are checked against real music catalogs, job searches open on LinkedIn and Indeed, and day plans come with a calendar file.

Private by design

Tools only read what you send them. We don’t store your requests or the answers.

Connect

Connect in three steps

  1. Copy the addressCopy the AI Verse MCP server address above.
  2. Add it to your AI appIn your AI app’s settings, add a custom connector (it may be called a remote MCP server or an MCP integration) and paste the address. No sign-in is needed.
  3. Just askTry “Use AI Verse to make a rainy-day jazz playlist.” Your app will ask before it uses a tool.

Cursor and other apps with an MCP settings file

Add this to the app’s MCP settings.

{
  "mcpServers": {
    "ai-verse": {
      "url": "https://api.aiverse.it.com/mcp"
    }
  }
}

VS Code

Add this to your mcp.json.

{
  "servers": {
    "ai-verse": {
      "type": "http",
      "url": "https://api.aiverse.it.com/mcp"
    }
  }
}

Have an AIV key? Add the header Authorization: Bearer YOUR_KEY (some apps call it an access token or API key) to use your key’s monthly requests instead of the free daily allowance.

FAQ

Questions

Is it free?

Yes. Anyone can use the AI Verse MCP server with a daily allowance of free AI tool calls. Job search links and the app list don’t count toward it. For more, use an AIV key.

Do I need an account?

No. Paste the address and start. An AIV key is optional.

What happens to what I send?

The server uses your request only to answer it and doesn’t store the request or the answer. We keep a daily count per visitor, or a monthly count per AIV key, to apply limits. See our Privacy Policy.

Can the tools change anything in my accounts?

No. Every tool is read-only. It returns text, links, files or images, and never sends, buys or posts anything.

My app can’t connect. What should I check?

Make sure you pasted the full address ending in /mcp, and that your app supports remote MCP servers over HTTP (sometimes called Streamable HTTP). Still stuck? Email team@aiverse.it.com.
