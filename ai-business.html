      Use your AI anywhere

      Six ways to use it. The first four run on AI Verse and are ready now. Hosting it yourself or using it in an app needs an AI API key.

      1. Share link Ready now

      A page anyone can open to chat with your AI. Send it, post it, or print the QR code.

      Open
      Add it to a phone like an app
      1. iPhone: open the link in Safari, tap Share, then Add to Home Screen.
      2. Android: open it in Chrome, tap the ⋮ menu, then Add to Home screen.

      2. Chat bubble on your website Ready now

      A chat button in the corner of every page. Paste this just before </body>.

      Step-by-step for WordPress, Wix, Squarespace and Shopify
      1. WordPress: install the free WPCode plugin, open Code Snippets → Header & Footer, paste into Footer and save.
      2. Wix: Settings → Custom Code → + Add Custom Code, paste, choose All pages and Body - end, apply and publish.
      3. Squarespace: Settings → Developer Tools → Code Injection, paste into Footer and save (paid plans).
      4. Shopify: Online Store → Themes → ⋯ → Edit code → theme.liquid, paste before </body> and save.
      5. Your own HTML site: paste before </body> on each page and upload.

      3. Chat inside a page Ready now

      The full chat inside one page, like a Help or Contact page.

      Where to paste it
      1. WordPress: add a Custom HTML block to the page.
      2. Wix: Add → Embed Code → Embed HTML, then resize the box.
      3. Squarespace: add a Code block.
      4. Shopify: edit the page, press Show HTML (<>), paste.
      5. Your own HTML site: paste where the chat should appear.

      4. Download your AI file Ready now

      One .aiv file with everything your AI knows: instructions, knowledge, files and personality. Keep it as a backup, or upload it again with Upload AI file at the top of the builder to restore or copy it.

      5. Self-host kit Needs an AI API key

      Run your AI on your own server and address. One file gives you a chat page, a chat bubble and the AI connection. Free to host on Cloudflare.

      How to set it up
      1. Get an AI API key. We recommend an AIV API key.
      2. Unzip the kit. In Cloudflare: Workers & Pages → Create → Create Worker → Deploy → Edit code.
      3. Paste worker.js, press Deploy.
      4. Settings → Variables and Secrets → add a Secret named AI_API_KEY with your key → Deploy.
      5. Open your worker's address. For a bubble, paste <script src="https://YOUR-WORKER-ADDRESS/widget.js" defer></script> on your site.

      6. Use it in your app (API) Needs an AI API key

      Use your AI in apps and tools with any OpenAI-compatible library and an AIV API key. Keep the key on your server.
