MCP
Use AI Verse in Claude, ChatGPT and other AI apps

    
The AI Verse MCP server gives any app that supports the Model Context Protocol a set of free AI Verse tools. Add this address as a custom connector (some apps call it a remote MCP server):

    
https://api.aiverse.it.com/mcp

    
Free to try, with a daily limit on AI tools. For unlimited use, set the access token (header) to Authorization: Bearer YOUR_KEY with your AIV key. Each AI tool call counts as one request.

    
For apps that use a settings file, such as Cursor:

    
{
  "mcpServers": {
    "ai-verse": {
      "url": "https://api.aiverse.it.com/mcp",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

Questions
Good to know

    
What counts as a request?
Each call to /v1/chat/completions counts as one request, whether it's short or long and whether it streams. Checking usage and listing models are free.

    
What happens if I reach my limit?
Requests return a 429 error with a message saying when your allowance resets, on the 1st of each month. You can upgrade anytime in the billing portal and the new limit applies right away.

    
Do you store my prompts?
No. The AIV API passes your request to its model provider and returns the answer without saving prompts or responses. We store only your plan, subscription status, request count and a scrambled (hashed) copy of your key.

    
I lost my key. Can you send it again?
For your security, nobody can look up a key after it's shown, including us. If you still have it, use Replace key above. If it's lost, email team@aiverse.it.com from the address you subscribed with.

    
Can I cancel?
Yes, anytime in the billing portal. Your key keeps working until the end of the period you paid for, then stops.
